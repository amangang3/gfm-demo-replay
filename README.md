# git-for-memory v2: demo replay

A recorded run of the git-for-memory v2 demo (MIT AI Studio), replayed step by step in the browser.

**Watch it:** https://amangang3.github.io/gfm-demo-replay/

The page shows the run of 2026-11-15 (19/19 checks). It was generated with `demo/export_replay.py` from the run's own artifacts: the session logs, the memory store's git history, the memory given to each Claude session, and the files Claude wrote. Nothing is simulated. All projects and sessions are fictional.
